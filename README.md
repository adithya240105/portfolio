- **Filterable Competencies Matrix**: Interactive domain filtering for Operations Strategy, Maintenance, Automation, ESG/Statutory, and Leadership.
- **Credential Showcase**: Fanuc CNC Specialist, CMTI, ISO 14001/45001 Auditor, and "C" Certified Competent Person License.
- **Direct Recruiter Connect**: One-click direct email generator, WhatsApp messaging link, phone call link, and downloadable CV & Cover Letter.
- **Print / PDF Ready**: Tailored `@media print` CSS so recruiters can print directly to an executive paper format.
- **Social Media Ready**: Built-in OpenGraph (OG) and Twitter Card metadata for rich previews when shared on LinkedIn or WhatsApp.

## 🚀 How to Host & Get Your Live URL (Free & Fast)

To add the URL to LinkedIn and job applications, host it using one of the following free, permanent methods:

### Option 1: GitHub Pages (Recommended — Takes 2 Minutes)

1. Create a free account at [GitHub](https://github.com) if you haven't already.
2. Create a new repository named `portfolio` (or `durairajan-portfolio`).
3. Open your terminal in this folder (`c:\Users\ad117442\Desktop\Port`) and run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Executive Portfolio"
   git branch -M main
   git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/portfolio.git
   git push -u origin main
   ```
4. On GitHub, go to your repository **Settings** → **Pages**.
5. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
6. Within 60 seconds, your site is live at:
   ```
   https://<YOUR-GITHUB-USERNAME>.github.io/portfolio/
   ```

---

1. Visit [Netlify Drop](https://app.netlify.com/drop).

## 💼 Adding to LinkedIn & Job Portals

### 1. On LinkedIn:
- **Featured Section**: Click **Add profile section** → **Featured** → **Links**, paste your live portfolio URL. Title: *"Executive Portfolio | 30+ Years Service Operations & Maintenance Leadership"*.
- **Contact Info**: Go to your profile header → **Contact info** → **Add website** → paste the portfolio URL with type *"Personal / Portfolio"*.
- **Headline / Summary**: Mention: *"Explore my portfolio & operational case studies: [Your URL]"*.

### 2. On Job Portals (Naukri, Indeed, IIMJobs, Foundit):
- Add the link into the **Portfolio / Website URL** field of your profile.
- In your cover letter or introduction message to recruiters, include:
  > *"You can review my detailed operational case studies, certifications, and track record at: [Your URL]"*
